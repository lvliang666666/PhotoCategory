1. 项目是什么

「相册分类」（包名 photo_storer）是面向 Android 的本地照片整理应用。设计哲学是温和的低饱和配色 + 黏土卡片式界面，核心原则「本地优先、隐私保护」——应用绝不扫描或自动导入系统图库，只有用户主动选择的照片才进入应用。

核心功能

  • 层级化整理：相册 → 一级子相册，支持相册描述、彩色主题、图标、自定义封面；照片可关联多个分类。
  • 图库与时间线：全部照片 / 收藏 / 最近浏览 / 最近添加智能入口；按文件名、分类、标签、格式、方向、收藏、拍摄日期筛选；按年月组织时间线。
  • 导入导出：从系统照片选择器批量导入（读 EXIF 拍摄时间）；单相册 ZIP 打包分享；「完整相册包」导出 / 恢复（含照片、层级、标签、收藏、浏览记录、私密凭据，恢复前校验格式与引用）。
  • 隐私安全：六位数字应用锁（后台重锁、错误限制、短暂锁定）；私密相册独立密码 + 隐藏入口；密码加盐哈希存储；AI API Key 走 Android Keystore 加密。
  • AI 朋友圈文案：可配置 DeepSeek API，四种风格生成最多三条文案；AI 只收元数据（文件名 / 时间 / 尺寸 / 故事 / 描述），不上传照片原图。

2. 怎么跑起来

环境要求

  • Flutter SDK（Dart ^3.2.0）、Android SDK、Java/Kotlin 17；Gradle wrapper 已升到 8.14

构建步骤

  1. 拉依赖：
    flutter pub get
  2. 日常运行（项目定义 standard / zero 两个 flavor）：
    flutter run --flavor standard
  3. 跑测试：
    flutter test
  4. 一键部署到连接的手机（项目自带脚本）：
    deploy.bat            # 或 scripts\deploy.ps1
connect-phone.bat     # 先连接手机
  5. 发版构建：
    flutter build apk --release --flavor standard
发版产物归档在 releases/（67M，已被 .gitignore 排除不进 git）。

3. 怎么用

  1. 首次启动：应用明确提示「不会扫描系统图库」——点导入从系统照片选择器批量选照片，EXIF 拍摄时间自动读取。
  2. 建相册：相册总览页新建，设置颜色 / 图标 / 描述 / 封面；相册内可再建一级子相册。
  3. 整理：图库页批量添加 / 移除分类和标签、批量收藏；时间线按年月回看。
  4. 隐私：设置页开六位应用锁；私密相册单独设密码，可隐藏入口。
  5. AI 文案：选照片 → 填场景说明 → 选风格（自然日常 / 文艺克制 / 轻松幽默 / 电影旁白）→ 生成三条可编辑文案；API Key 在设置页配置（DeepSeek）。
  6. 备份：设置页导出「完整相册包」，换机用恢复功能导入（校验格式与数据引用）。

5. FAQ

Q：为什么 App 里看不到我手机里的全部照片？

设计如此——本地优先 + 隐私保护，不扫描系统图库。要用哪张照片就从选择器主动导入哪张。

Q：AI 文案会泄露照片吗？

不会。AI 只接收文件名、拍摄时间、尺寸、照片故事、相册描述和补充说明这些元数据，原图永不上传。

Q：应用锁密码忘了？

应用锁与私密相册密码是加盐哈希存储，无法找回；完整相册包恢复会带凭据，但前提是你有之前的备份。

Q：standard 和 zero 两个 flavor 有什么区别？

项目定义的两个产品 flavor，日常开发用 standard；具体差异见 android/build.gradle 配置。

Q：构建报 Gradle 版本错误？

wrapper 已升到 8.14（Flutter 最低版本要求），确认本地 Gradle 未被覆盖。
